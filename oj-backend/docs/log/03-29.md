## GlobalHeader 全局搜索功能修复（2026-03-29 17:15）

### 问题描述
GlobalHeader 搜索框输入关键词后跳转到 `/questions?search=xxx`，但 QuestionsView 未读取该参数，导致搜索无效。

### 解决方案
修改 QuestionsView.vue，在 onMounted 中读取 route.query.search 参数并设置到 searchParams.title。

### 修改文件
- `oj-frontend/src/views/question/QuestionsView.vue`
  - 第 303 行：添加 `useRoute` 导入
  - 第 489 行：添加 `const route = useRoute();`
  - onMounted：添加搜索参数处理逻辑

### 代码变更
```typescript
// 导入
import { useRouter, useRoute } from "vue-router";

// 变量
const route = useRoute();

// onMounted 处理
onMounted(() => {
  // 处理全局搜索参数
  const searchQuery = route.query.search as string;
  if (searchQuery && searchQuery.trim()) {
    searchParams.value.title = searchQuery.trim();
    searchKeyword.value = searchQuery.trim();
  }
  loadData();
  // ...
});
```

### 测试验证
- GlobalHeader 输入关键词 → 跳转题目页 → 自动搜索并显示结果
